# 关于本站

YHuo 是一个部署在 Cloudflare Pages 和 GitHub Pages 上的个人主页，前台是单个 `index.html`，管理后台在 `/admin`。

## 首页

- **时钟**：毫秒级本地时间 + 时段问候语 + 每日一言（管理员可在后台设置固定寄语）
- **天气**：日期下方显示当前城市天气，点击胶囊可更换城市
- **图片画廊**：牌堆式轮播，点击进入相册界面

## 相册

顶栏「相册」进入，按后台设置的相册分组展示照片墙，支持灯箱大图、键盘翻页。登录后可以在大图右上角点 ♥ 收藏照片。

## 音乐

底部悬浮播放器，支持播放列表、顺序/随机/单曲循环。播放列表里每首歌可以点 ♥ 收藏。

## 个人中心

登录后点头像打开菜单：我的主页（资料、收藏、修改密码）、更换头像、退出登录。开放注册，账号数据保存在服务端。

## 外观自定义

右下角箭头打开外观抽屉：主题色、自定义背景图、背景变暗、动效开关。管理员在后台设置的是全站默认值，访客自己的选择优先。
