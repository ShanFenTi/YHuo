# 更新日志

## 2026-08-31

* **首页修复**：修复天气胶囊被拉伸占满整行、右侧大片留白的问题，现在按内容自适应宽度

* **AI 助手**：对话记录服务端保存（按账号隔离，每人最多 200 条，刷新/换界面后自动恢复）；关闭界面不再清空对话，点「新对话」才清（本地+服务端一起清）；退出登录清空内存对话防止串号

* **AI 助手**：多对话管理——历史对话改为抽屉式（默认收起，顶栏气泡按钮唤出，点聊天区/选完对话自动关闭，全屏宽一致）；新对话/切换历史对话继续聊/删除带确认框，对话自动以第一句命名，最多 50 个；旧的单条历史自动归入"历史对话"

* **邮箱体系**：后台新增「邮件」设置页（Resend/Brevo 双协议，API Key 存 D1 不回显，测试发送）；启用后前台开放——注册需邮箱验证码、登录卡片新增「忘记密码」（邮箱验证码重置，重置后踢全部设备）、个人主页可绑定/换绑邮箱并开启**登录二次验证**（2FA）；验证码 6 位、10 分钟有效、限 5 次尝试、60 秒重发间隔；未配置邮件服务时所有邮箱相关 UI 自动隐藏，注册流程不变

* **邮箱·仅站长模式**：邮件页新增「仅站长使用」开关——无域名邮件服务（如 Resend onboarding 只能发给自己）场景下，普通用户注册不要求邮箱、看不到邮箱卡，只有站长邮箱（后台单独填写）能收验证码/绑定/开 2FA/找回密码
