# 更新日志

## 2026-09-01

* **课表提醒**：后台「邮件」页新增「发送测试提醒」——不用等真实到点，按真实课表算出"今天该发什么"并立即发送早报 / 课前提醒样式的【测试】邮件，主动验证 解析→计算→拼邮件→发送 全链路；收件邮箱可指定（留空=站长邮箱，仅站长模式下只能发站长邮箱），需是绑定了已验证邮箱且启用过课表的账号；测试发送不写防重发记录，不影响真实提醒；发送结果回显教学周/星期/今日课程数，测试邮件计入邮件统计（"课表提醒测试"）

## 2026-08-31

* **课表**：新增"移除课表"——提醒设置区底部红色按钮，自定义确认框二次确认后删除服务端的全部课程/作息/提醒设置（提醒邮件随之停止）；没启用过课表的账号个人主页只显示"＋ 启用课表"入口行，不再直接铺开空表格

* **后台**：邮件设置支持移除站长邮箱——清空"站长邮箱"输入框后点"保存配置"即移除（原先清空保存仍保留旧值，无法移除）；若"仅站长使用"处于开启状态会自动关闭，输入框下方提示已说明

* **课表修复**：修复 WakeUp JSON 导入报"没有解析到有效课程"——部分版本导出的字段名不同（name/teacher/room/startSection/endSection、weeks 为文本如"1-16"、"2-16双"），解析器已全部兼容（已用真实导出文件验证 14 门课全部正确解析，双周课周次正确）

* **课表**：导入支持 WakeUp 的 CSV 格式（此前仅 JSON）——按表头名匹配列（课程名/星期/讲师/节数/教室/周次，兼容列序变化和别称），支持"第1,2节"、"周一"等中文写法、带引号转义的字段和 BOM；前端按扩展名+文件内容自动分流两种格式

* **课表**：修复个人主页课表卡「作息时间」展开后布局错乱——格子里"第N节"文字和时间输入框横向溢出互相挤压，改为标签在上、输入框占满整格的纵向排列

* **课表提醒（新功能）**：个人主页新增「课表」卡——周视图展示本学期课程（按教学周过滤、可切周），支持导入 WakeUp 课程表导出的 JSON（解析在服务端，保留提醒设置）+ 手动添加/编辑/删除课程；提醒设置支持每日早报（每天固定时间一封列出当天所有课）和重点课课前提醒（勾选的课程提前 N 分钟单独发邮件），作息时间（各节上课时间）可自定义；后台「邮件」页新增定时任务配置——显示 tick URL、复制/重新生成密钥、手动执行一次，需配合外部 cron（推荐 cron-job.org 每 5 分钟）触发。提醒发给用户绑定的已验证邮箱

* **首页/杂项**：顶栏新增「杂项」全屏界面；首页的图片画廊（折叠牌堆轮播）迁入杂项界面，首页不再直接展示图片（相册界面不受影响）

* **首页**：普通用户登录成功后也弹顶部欢迎浮窗（👋 欢迎回来，用户名；不显示"进入后台"按钮，6 秒自动消失）；管理员浮窗行为不变

* **首页**：退出账号后弹顶部浮窗提示「👋 已退出登录，期待下次再见」；关闭登录卡片改为上飘滑出退场动效（点击空白处/登录成功关闭时卡片向上浮起淡出）

* **首页**：登录卡片的登录/注册/找回密码/验证码模式切换改为平滑过渡——邮箱、验证码、密码等输入行高度渐展开收起，注册按钮宽度渐变，副标题与提交按钮文案淡出淡入（尊重系统"减少动态效果"设置）

* **首页修复**：修复天气胶囊被拉伸占满整行、右侧大片留白的问题，现在按内容自适应宽度

* **后台**：用户列表显示注册用户的头像（没设头像的仍显示用户名首字徽章）

* **首页**：未播放音乐时，歌词横条改为显示一言（管理员寄语 > 每日一言当日缓存 > 待机提示）

* **首页**：一言从歌词横条移出，改为天气胶囊下方的独立胶囊（与天气同款样式，打字机轮播）；点击一言胶囊可立即切换下一句

* **后台**：主页寄语支持保存多条（最多 20 条）；前台寄语/一言打字机轮播（没配寄语或只配一条时拉 6 条一言混合轮播，3 秒切一句，主域名失败自动换国际备用域名）；一言改为天气胶囊同款样式；修复刷新后自动接续播放导致歌词条待机一言被歌名覆盖的问题

* **AI 助手**：对话记录服务端保存（按账号隔离，每人最多 200 条，刷新/换界面后自动恢复）；关闭界面不再清空对话，点「新对话」才清（本地+服务端一起清）；退出登录清空内存对话防止串号

* **AI 助手**：多对话管理——历史对话改为抽屉式（默认收起，顶栏气泡按钮唤出，点聊天区/选完对话自动关闭，全屏宽一致）；新对话/切换历史对话继续聊/删除带确认框，对话自动以第一句命名，最多 50 个；旧的单条历史自动归入"历史对话"

* **邮箱体系**：后台新增「邮件」设置页（Resend/Brevo 双协议，API Key 存 D1 不回显，测试发送）；启用后前台开放——注册需邮箱验证码、登录卡片新增「忘记密码」（邮箱验证码重置，重置后踢全部设备）、个人主页可绑定/换绑邮箱并开启**登录二次验证**（2FA）；验证码 6 位、10 分钟有效、限 5 次尝试、60 秒重发间隔；未配置邮件服务时所有邮箱相关 UI 自动隐藏，注册流程不变

* **邮箱·仅站长模式**：邮件页新增「仅站长使用」开关——无域名邮件服务（如 Resend onboarding 只能发给自己）场景下，普通用户注册不要求邮箱、看不到邮箱卡，只有站长邮箱（后台单独填写）能收验证码/绑定/开 2FA/找回密码

* **邮箱·管理员**：后台「我的」页新增管理员邮箱绑定/解绑（验证码验证，存 site\_settings）；后台登录页新增「忘记密码？」（邮箱验证码重置管理员密码，重置后踢掉全部管理员会话）；未启用邮件服务时入口自动隐藏
