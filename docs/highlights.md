# 关于本站的工程亮点

> 这个站不只是「一个好看的首页」——它跑在 Cloudflare Pages 上，前台纯静态零构建，后端是边缘函数 + D1 数据库 + KV 存储。下面这些是做的时候比较得意的几处，写给感兴趣的朋友。

## 🎵 切页音乐不断播

站内跳转走 pjax——只替换内容区的 `<main>`，播放器住在外壳里不参与替换。所以你从首页听到一半的歌，逛到工具页、留言板再回来，进度、歌词、律动全都还在。整站没有任何框架，纯手写的路由替换。

## 🤖 AI 助手：Key 永远不碰浏览器

AI 页支持多家模型供应商（OpenAI 兼容格式 / Anthropic 原生协议），所有对话经服务端边缘函数转发——上游 API Key 只存在服务端配置里，前端永远接触不到。后端把两家协议的流式响应归一化成同一种格式再转发，加新供应商不用改前端。现在还支持多模态图片、语音输入、多人格预设与多对话管理（对话存数据库，换设备不丢）。

## ⏰ 课表提醒：一条完整的定时任务链

Pages Functions 本身不支持定时触发，所以课表提醒靠外部 cron 每 5 分钟敲一次带密钥的接口：到点判断当天课程、算好提前量、发提醒邮件，幂等设计保证不重发。每天早上，你会收到一封「今日课表」；重点课前 15/30/60 分钟，会再收到一次提醒。

## 📦 每日自动备份

每天定时任务会顺带把留言、随笔、签到、用户四张表全量打包存进 KV 存储，自动保留最近 7 份，后台一键下载。免费档的 D1 没有官方自动备份，这是自己补上的一块数据安全板。

## 🔗 不止静态：短链 / 数据接口 / RSS

- `/s/码` 短链服务：302 跳转带点击计数，后台管理；
- `/api/summary` 公开聚合统计（只给数字，绝不给任何个人数据）；
- `/feed.xml` RSS 订阅——用你喜欢的阅读器订阅本站随笔；
- PWA 可安装到桌面/手机，断网时打开过页面也能浏览。

## 🎨 视听细节

流星雨按视口几何自适应出生带（窄屏也能铺满全屏）、下雨天页面会真的落雨丝、播放音乐时歌词条打字机逐句跟唱、可选频谱面板随节拍舞动、每日壁纸一键换新。所有动效都尊重系统的「减少动态效果」设置。

## 🛠 工程纪律

- 零构建、零 npm 运行时依赖——改完直接部署；
- 每次提交前跑自研校验脚本（九页外壳一致性比对 + 全接口语法检查），push 时 GitHub Actions 再跑一遍；
- 颜色全走语义变量，深浅主题自动跟随；
- 深夜写代码的 AI 和人类共同维护 😄
